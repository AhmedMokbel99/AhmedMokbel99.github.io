# دليل التفعيل المجاني — Search Console وGoogle Business Profile

كل الخطوات هنا مجانية بالكامل. الموقع نفسه مستضاف على GitHub Pages بدون أي تكلفة،
ولا يحتاج تجديدًا أو سيرفر.

## 1) Google Search Console

**ليه؟** يوريك الكلمات اللي بتجيب زوار، وأي صفحة فيها مشكلة، وهل جوجل فهرس الصفحات.

**الخطوات:**

1. افتح <https://search.google.com/search-console> بحساب Google الخاص بك.
2. اضغط **Add property** واختر **URL prefix**.
3. اكتب: `https://ahmedmokbel99.github.io/`
4. اختر طريقة التحقق **HTML file**:
   - جوجل هيديك ملف اسمه مثل `google1234567890abcdef.html`.
   - ابعت اسم الملف لي، وأنا أضيفه للموقع وأعمل نشر.
   - ارجع لـ Search Console واضغط **Verify**.
5. بعد التحقق: من القائمة الجانبية **Sitemaps**، اكتب `sitemap.xml` واضغط **Submit**.

**ملاحظات:**

- لا تحتاج دومين مخصص ولا DNS.
- التحقق بـ HTML file يفضل يبقى موجودًا في الموقع بشكل دائم.
- بعد الفهرسة، تقدر تشوف تقارير **Performance** و**Pages**.

## 2) Google Business Profile (ملف DOT Media)

**ليه؟** يظهر DOT Media في خرائط جوجل ونتائج البحث المحلية («موشن جرافيك المنصورة» وغيرها).

**الخطوات:**

1. افتح <https://business.google.com> بحساب Google الخاص بك.
2. اضغط **Add business** واكتب اسم النشاط: `DOT Media`.
3. الفئة: **Graphic designer** أو **Video production service** (اختر الأنسب).
4. منطقة الخدمة: المنصورة، الدقهلية (ومصر لو بتخدم عن بُعد).
5. أضف رقم واتساب/الهاتف والبريد، والموقع: `https://ahmedmokbel99.github.io/`.
6. أكمل التوثيق (فيديو أو مكالمة أو بطاقة بريدية حسب ما يطلبه جوجل).
7. أضف الصور: صورة شخصية، شعار، 3–6 نماذج من أعمالك.
8. بعد القبول، اطلب من 3–5 عملاء تقييمًا — التقييمات أهم عامل ظهور محلي.
