Ahmed Mokbel — Portfolio API

A public, read-only JSON API generated from the same content as the portfolio. It is the machine-readable mirror of the site: the same projects, the same case studies, the same services.

Honest description of the architecture. This is a static API. Every response is a pre-rendered JSON file published on GitHub Pages and regenerated on each deploy. There is no server, no database, no query language and no rate limiter — so there is also nothing to abuse beyond reading public content.

Example

curl -s https://ahmedmokbel99.github.io/api/projects.json | head -c 400
curl -s https://ahmedmokbel99.github.io/api/projects/project-f26.json

Conventions

  • Method: GET only. Every other method returns the static host's default error.
  • Content type: application/json; charset=utf-8.
  • Encoding: UTF-8, Arabic text is not escaped (ensure_ascii=false).
  • Query parameters are not supported — the path is the whole request.
  • Unknown slugs return the static host's 404 page, not a JSON error body.
  • Timestamps use ISO 8601 dates and refer to the last build.

Authentication and rate limits

None and none. All data is public portfolio content intended for humans and agents alike. See auth.md for the full access statement.

CORS

GitHub Pages answers every request with Access-Control-Allow-Origin: *, so browser-based agents can call the API directly.

Caching

Responses carry an ETag and short Cache-Control headers from the host. Files change only when the site is redeployed.
