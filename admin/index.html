تحكم كامل في نصوص الموقع ومشاريعه

إزاي أعمل التوكن؟ (مرة واحدة — مجاني)
  1. افتح GitHub → Fine-grained tokens.
  2. اختار Only select repositories وحدد مستودع الموقع فقط.
  3. من Repository permissions فعّل Contents: Read and write وMetadata: Read.
  4. حدد مدة صلاحية (سنة مثلاً)، ثم Generate token وانسخه هنا.

التوكن بيتخزن في متصفحك فقط، مش في الموقع ولا في المستودع.
